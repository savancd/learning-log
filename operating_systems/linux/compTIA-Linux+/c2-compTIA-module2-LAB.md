# This is LAB excercises for CompTIA Linux+


First should open a terminal in which is intended to work on.		

First what should be done is to create environment variable. 
Variable name is written with uppercases (it can be done even with lower case letters) but the standard way is to use CAPITAL letters.


Example:

```bash
$ VAR="Hello World"
```

To be printed on the screen you can use:

```bash
# In the terminal just type
$ echo $VAR
```



To be able to use that environment variable in some other session you should make it and export is as is in following example:

```bash
$ export VAR="Hello World"
```


Whenever you want to use that environment variable in some other session you should first export it.
